ADB 常用命令
  • 连接设备
    adb connect <ip>:<port>
  • 断开连接
    adb disconnect
  • 查看已连接设备
    adb devices
  • 安装 APK
    adb install app.apk
  • 卸载应用
    adb uninstall <包名>
  • 推送文件到手机
    adb push local.txt /sdcard/
  • 从手机拉取文件
    adb pull /sdcard/file.txt ./
  • 截屏
    adb shell screencap /sdcard/screen.png
  • 录屏
    adb shell screenrecord /sdcard/video.mp4
  • 查看日志
    adb logcat
  • 进入 Shell
    adb shell
  • 重启设备
    adb reboot
  • 重启到 Recovery
    adb reboot recovery
  • 查看系统属性
    adb shell getprop ro.build.display.id
  • 查看已安装应用
    adb shell pm list packages
